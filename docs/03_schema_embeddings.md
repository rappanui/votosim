# VotoSim — Schema: Embeddings and Similarity Cache (v2 only)

**Context:** Vector similarity infrastructure for the v2 hybrid match algorithm. Not active in MVP — these tables will be empty until the v2 pipeline runs. The `vector` extension is already enabled. Read before implementing semantic search or the v2 match score.

---

## MVP Behavior

In MVP, `score_semantico = 0` for all candidates (no embeddings). The scoring formula `score_final = score_tematico × 0.7 + score_semantico × 0.3` degrades gracefully to `score_final = score_tematico × 0.7`. No code changes needed — the Edge Function already handles missing embeddings with `COALESCE(..., 0)`.

---

## Table: `politician_embeddings`

One row per politician. Generated by the pipeline from `politician_positions` + plan summary.

| Column | Type | Notes |
|---|---|---|
| `politician_id` | UUID PK FK | |
| `embedding` | vector(1024) | Voyage AI `voyage-large-2` output (1024 dimensions) |
| `texto_fonte` | TEXT | Exact input text used to generate embedding (for debugging/regen) |
| `versao_schema` | SMALLINT | Increment when the embedding template changes → triggers full regen |
| `valido_ate` | DATE | TTL — pipeline regens after this date |
| `tokens_usados` | INTEGER | For Voyage AI free tier tracking |

**Embedding input template** (version 1 — change `versao_schema` if you modify this):
```
Nome: {nome_urna}
Partido: {partido_atual}
Cargo disputado em 2026: {cargo} pelo estado de {estado}
Posições favoráveis: {slug (intensidade X)} | ...
Posições contrárias: {slug (intensidade X)} | ...
Temas bandeira: {slugs with intensidade >= 4}
Resumo plano de governo: {plano_governo_resumo}
```

**pgvector cosine distance operator:** `<=>` (lower = more similar; convert to similarity: `1 - (a <=> b)`)

---

## Table: `similarity_cache`

Pre-computed cosine similarity for pairs of politicians. Avoids real-time pgvector queries per user session.

| Column | Type | Notes |
|---|---|---|
| `politician_id_a` | UUID | Always the lexicographically smaller UUID (enforce: `id_a < id_b`) |
| `politician_id_b` | UUID | |
| `similarity_coseno` | NUMERIC(5,4) | Raw cosine similarity 0.0–1.0 |
| `similarity_final` | NUMERIC(5,4) | May include additional adjustments |
| `valido_ate` | TIMESTAMPTZ | 24h TTL — pipeline recomputes daily |

**UNIQUE:** `(politician_id_a, politician_id_b)` where `id_a < id_b`.

**Threshold:** only pairs with `similarity >= 0.3` are stored (very dissimilar pairs skipped).

---

## View: `v_embeddings_desatualizados`

Returns politicians who have positions but either: no embedding exists, or `valido_ate` is past, or `versao_schema` is outdated. Used by pipeline to determine who needs re-embedding.

## Voyage AI Notes

- Model: `voyage-large-2` (1024 dimensions)
- Free tier: 200M tokens/month — sufficient for all ~5,100 candidates
- API endpoint: `https://api.voyageai.com/v1/embeddings`
- Rate limiting: 200ms between calls to stay within free tier limits
- API key: `VOYAGE_API_KEY` in pipeline `.env` (not needed by the frontend or Edge Functions)
